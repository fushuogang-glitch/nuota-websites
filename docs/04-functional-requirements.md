# 04. 两个官网功能需求

## 通用功能

- 响应式布局：移动端优先，PC 端展示完整卡片矩阵
- SEO：每页可配置 title / description / og image / canonical
- 统计埋点：PV、按钮点击、表单提交、预约演示转化
- 表单：预约演示、咨询提交、电话/微信/公众号入口
- 内容管理：Hero、卡片、Agent 矩阵、定价、案例、FAQ 可后台维护
- 性能：首屏图片压缩，LCP 控制在 2.5s 内，移动端避免重型动效
- 合规：页脚展示公司主体、ICP备案、隐私政策、用户协议

## `nuotaai.cn` 产品官网功能模块

### Header

- Logo：诺塔 NUOTA
- 锚点导航：产品作用 / 产品特点 / Agent 矩阵 / 美业版 / 定价 / 案例
- 固定 CTA：预约演示

### Hero

- 支持首屏视频或静态背景；如无产品视频，先用静态渐变 + 文字标
- 主标题三行结构：产品名 / 英文名 / Slogan
- 副文案支持换行控制
- 双按钮：预约演示 / 查看定价

### 品类定义模块

- 三列对比：CRM / ERP / 诺塔 NUOTA
- 支持 icon 或简洁图形，不要用复杂插画

### 作用与特点模块

- 4 个作用卡片 + 5 个特点卡片
- 卡片字段：序号、标题、描述、icon
- 支持后台排序

### Agent 矩阵

- Agent 卡片字段：编号、名称、emoji/icon、职责、触发动作、所属版本
- 支持“9 个 / 12 个”配置切换，避免口径写死
- 智总 Agent 单独高亮

### OTA 执行模型

- 三步流程：Objective / Task / Agent
- 移动端改为纵向时间轴
- 可配一句底部总结

### 定价模块

- 两档套餐卡片：单店版 / 连锁版
- 推荐标签：默认推荐单店版，连锁客户突出“第 2 店起每店 ¥1,500/月”
- 字段：套餐名、价格、计费周期、连锁加价规则、功能点、按钮链接、是否推荐
- 支持“按月付费，具体功能以实际开通版本为准”说明

### 案例模块

- 案例卡片：城市、客户名、门店数、使用产品、成果描述、标签
- 支持“种子客户 / 战略咨询 / 系统重建”等标签
- 未授权客户支持匿名化，例如“武汉某连锁品牌”

### 预约演示表单

字段：

```text
name：姓名，必填
phone：手机号，必填，校验中国大陆手机号
store_count：门店数量，单选
city：城市，必填
pain_point：当前最头疼的问题，单选/多选
source：来源渠道，隐藏字段，自动从 URL 参数读取
message：备注，选填
```

提交后：

- 成功提示：已收到预约，顾问将在 1 个工作日内联系你
- 失败提示：提交失败，请稍后重试或添加企业微信
- 通知：邮件/企业微信 webhook/CRM，三选一或并存

### FAQ

建议问题：

- 需要购买硬件吗？
- 上线周期多久？
- 数据安全怎么保障？
- 支持连锁多店吗？
- 和现有 CRM/ERP/收银系统能对接吗？
- Agent 会不会替代员工？

## `tataasia.com` 集团站功能模块

- 保留现有咨询站结构
- 服务卡片 04 改为诺塔入口
- 新增“集团旗下品牌”区块，后台可维护
- 案例区块支持标签筛选：战略咨询 / 诺塔 NUOTA / 系统重建 / 连锁扩张
- 咨询通道支持三卡片：一诺 / 拓疆 / 诺塔产品演示

## 技术实现建议

如果是静态站：

```text
Next.js / Astro / Nuxt 均可
内容先用 Markdown/JSON 配置，后期再接 CMS
```

如果是现有 HTML 修改：

- 先做全局搜索替换，再改首页与品牌页模块
- 旧 URL 保留并做 301，避免已收录页面流量丢失
