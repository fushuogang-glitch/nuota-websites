## 第五屏：Agent 矩阵

标题：

```text
AI Agent 数字员工，各司其职全天候运转
```

副标题：

```text
每个 Agent 专注一个经营环节，协同完成目标拆解、过程跟进、风险预警和结果反馈。
```

模块展示要求：

- 每个 Agent 一张卡片：编号 / 名称 / 一句话职责 / 触发动作
- 支持后续从 CMS 维护 Agent 列表
- 如果保留旧页 BA-01～BA-11 + 智总，需要统一到 9 或 12 的口径

示例卡片：

```text
数据信息 Agent
每日自动汇总经营数据，生成结构化日报，异常智能预警。

流程检查 Agent
每日巡检 SOP 执行情况，偏差立即预警，标准不打折。

智总 Agent
统筹其他 Agent，负责异常升级、执行调度和跨模块协同。
```
