# 02. 塔塔咨询集团站 `tataasia.com` 修改方案

## 总原则

`tataasia.com` 不推翻现有“塔塔咨询”定位，只做三件事：

1. 把所有“诺塔智控 / NOTA”替换为“诺塔 NUOTA / 诺塔智能体运营系统”。
2. 把诺塔从“门店 AI 管理系统”升级为“智能体运营系统”。
3. 增加集团旗下品牌关系，给 `nuotaai.cn` 导流。

## 首页 Hero 不建议大改

保留：

```text
让新美业持续盈利
TATA CONSULTING®
新美业战略咨询专家
```

可在副文案或按钮区增加一个入口：

```text
旗下产品：诺塔智能体运营系统 NUOTA Agentic OS →
```
